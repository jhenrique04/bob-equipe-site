# Página informativa do Bob Equipe

Site estático do projeto pessoal Bob Equipe. Mantido por [jhenrique04](https://github.com/jhenrique04).

Somente HTML e CSS, sem dependências ou JavaScript. A página descreve o estado do protótipo, suas integrações e o responsável. Não contém o código privado do agente, dados cadastrais da Meta, credenciais ou conteúdo das integrações.

Hospedagem prevista: GitHub Pages gratuito, neste repositório público. Não há domínio pago, serviços contratados, formulário, analytics próprio ou recursos de backend.

A publicação desta página não comprova aceitação do cadastro pela Meta nem resolução do erro 130497.

Para visualizar localmente, execute `python3 -m http.server 5193 --bind 127.0.0.1` nesta pasta e abra http://127.0.0.1:5193.
